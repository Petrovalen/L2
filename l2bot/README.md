# l2bot — автоматизация прокачки Lineage 2

> ⚠️ Автоматизация геймплея нарушает пользовательское соглашение Lineage 2
> (и офиц. серверов NCSoft, и большинства приватных). Реальный риск — **бан
> аккаунта**. Используешь на свой аккаунт и свой риск.

Модульный бот на Python: **захват экрана → анализ (CV/OCR) → ввод (DirectInput)**
и конечный автомат логики: *выживание → атака ближайшего моба → лут*.

## Архитектура

```
l2bot/
├── config.py             # ВСЕ настройки: координаты полосок, цвета, клавиши, пороги
├── main.py               # точка входа + главный цикл + горячие клавиши
├── tools_calibrate.py    # утилита подбора координат/цветов под свой клиент
├── capture/
│   └── screen.py         # захват экрана через mss (~5-10 мс/кадр)
├── vision/
│   ├── bars.py           # HP/MP/CP и HP цели по цвету пикселей
│   ├── targets.py        # поиск мобов через template matching (OpenCV)
│   └── ocr.py            # чтение текста через Tesseract (точечно)
├── control/
│   └── input_ctl.py      # клавиши/мышь через pydirectinput (+ "очеловечивание")
├── logic/
│   └── fsm.py            # конечный автомат: SEARCH → COMBAT → LOOT
└── templates/            # сюда класть скрины мобов для поиска
```

## Установка (Windows)

1. Python 3.10+.
2. Зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Tesseract OCR (если нужен OCR): установить и прописать путь в
   `config.TESSERACT_CMD`. Если OCR не используешь — можно игнорировать.

## Калибровка (обязательно перед первым запуском)

Координаты и цвета в `config.py` — это заглушки. Их надо подогнать под своё
разрешение и интерфейс, иначе бот читает мусор.

1. Запусти игру в **оконном режиме** (windowed / borderless).
2. Запусти `python tools_calibrate.py`.
3. Наводи курсор на края полоски HP (левый и правый), на середину по высоте —
   жми ПРОБЕЛ, записывай `x1`, `x2`, `y` и `color` в `config.BARS["hp"]`.
   То же для MP и (опц.) для полоски HP цели → `config.TARGET_BAR`.
4. Расставь клавиши в `config.KEYS` под свои макросы/хоткеи в игре.
5. (Опц.) Для поиска мобов положи их скрины в `templates/` и добавь пути в
   `config.MOB_TEMPLATES`. Без шаблонов бот выбирает цель клавишей
   `target_nearest`.

## Запуск

```
python main.py
```

> ⚠️ **Права администратора.** Если клиент L2 запущен «от имени администратора»
> (обычное дело), бота нужно запускать с **теми же правами** — иначе Windows
> блокирует передачу нажатий в окно игры, и клавиши не доходят (бот крутится, но
> в игре ничего не происходит). Запусти PowerShell от администратора и оттуда
> `python main.py`. Симптом несовпадения прав: в консоли идут строки состояния
> HP/MP/target, но игра не реагирует на клавиши.

- **F11** — пауза/продолжить
- **F12** — аварийный стоп
- Резкий увод мыши в левый верхний угол экрана — тоже аварийный стоп
  (failsafe pydirectinput).

## Как это работает

Каждую итерацию (`config.LOOP_DELAY`):
1. `capture` снимает кадр региона `config.CAPTURE_REGION`.
2. `vision.bars` считает HP/MP по доле «залитых» пикселей вдоль полоски и
   проверяет, есть ли выбранная цель.
3. `logic.fsm` решает действие: сначала выживание (хилка/мана по порогам),
   потом текущее состояние (искать цель / бить / лутать).
4. `control.input_ctl` шлёт клавиши/клики через DirectInput.

## Настройка поведения

Все пороги и тайминги — в `config.py`:
- `HP_HEAL_THRESHOLD`, `MP_MIN_THRESHOLD` — когда пить/хилиться.
- `ATTACK_TIMEOUT` — максимум времени на одну цель (если моб убегает/недостижим).
- `LOOT_TIME` — сколько собирать лут после смерти цели.
- `KEY_PRESS_*`, `HUMANIZE_JITTER` — «очеловечивание» ввода.
