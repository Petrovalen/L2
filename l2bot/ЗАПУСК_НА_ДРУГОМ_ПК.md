# Запуск l2bot на другом компьютере

Пошагово, с нуля. Всё под Windows.

> ⚠️ Автоматизация геймплея нарушает правила Lineage 2 — риск бана аккаунта.
> На свой аккаунт и свой риск.

---

## Что понадобится (установить один раз)

### 1. Python 3.10–3.12
- Скачать с https://python.org → **Windows installer (64-bit)**.
- При установке **обязательно отметить галочку «Add Python to PATH»**.
- Проверка: открыть `cmd` и ввести `python --version` — должна вывести версию.

### 2. Tesseract OCR (нужен для чтения цифр HP и имён мобов)
- Скачать установщик: https://github.com/UB-Mannheim/tesseract/wiki
- Установить в путь по умолчанию: `C:\Program Files\Tesseract-OCR\`
  (этот путь уже прописан в `config.py` → `TESSERACT_CMD`; если поставишь в
  другое место — поправь там путь).

---

## Установка бота

### 3. Скопировать проект
Либо `git clone`:
```
git clone https://github.com/Petrovalen/L2.git
```
либо просто скопировать папку `L2` целиком на новый ПК.

### 4. Поставить зависимости
Открыть `cmd` в папке `L2\l2bot` и выполнить:
```
pip install -r requirements.txt
```
Если `pip` не найден — используй `py -m pip install -r requirements.txt`.

### 5. Запуск
Двойной клик по **`run_bot_admin.bat`** в папке `l2bot`
(запросит права администратора — они нужны, чтобы ввод доходил до игры).
Откроется окно панели бота.

Лаунчер сам ищет Python (py launcher → PATH → типичные пути). Если всё же
пишет «Python не найден» — значит Python не установлен или не добавлен в PATH
(см. шаг 1). Как запасной вариант — задать переменную окружения
`L2BOT_PYTHONW` на свой `pythonw.exe`.

---

## ГЛАВНОЕ: калибровка на новом ПК (обязательно!)

Настройки калибровки хранятся в `l2bot\settings.json` — он **НЕ** копируется
через git (у каждого ПК/монитора свой). На новом компьютере его нет, поэтому
**всё нужно откалибровать заново** в панели. Разрешение/положение окна игры
у нового ПК другое — старые координаты не подойдут.

Что откалибровать (кнопки в панели, игра — в **оконном режиме**):

1. **Полоски HP/MP/CP** и **HP цели** (обвести рамкой). Если используешь чтение
   цифрами — включить «режим цифр» и проверить, что число читается.
2. **Зоны:**
   - «Зона поиска» мобов (плотно по игровому миру, без неба/чата/UI — чем
     меньше, тем быстрее);
   - «Точка персонажа» (небольшая область на персонаже);
   - «Стоп-зона (труп)» — область у персонажа, где не выделять труп;
   - «Зона баффов» (если используешь самобаффы).
3. **Клавиши** действий (атака, «ближайшая цель»/«следующая цель», подобрать,
   ассист, присесть и т.д.) — под свою раскладку макросов в игре.
4. **Ротация скиллов**, **лечение/банки**, **режим отдыха**, **самобаффы**.
5. **Список мобов** — свой для каждого профиля персонажа. Добавляется кнопкой
   по выделенному в игре мобу (снимается шаблон его ника). Общий стартовый
   список подтянется из `mobs.json`, дальше правишь под профиль.

Профили ПК и персонажа переключаются в панели — заведи свои.

## Arduino-мост ввода (опционально, но рекомендуется)

Игра может игнорировать программный ввод (после апдейтов клиента). Тогда ввод
идёт через плату Arduino (ATmega32U4: Leonardo/Micro/Pro Micro) как настоящая
клавиатура/мышь.

- Прошивка: `l2bot/arduino/l2bot_hid/l2bot_hid.ino` (залить через Arduino IDE
  или arduino-cli, плата `arduino:avr:micro`).
- Подключить плату по USB. Бот сам найдёт порт (по VID Arduino).
- Бэкенд ввода — `config.INPUT_BACKEND`:
  - `auto` (по умолчанию) — есть Arduino → через него, нет → через Windows;
  - `arduino` — только плата; `windows` — только программный ввод.
- Зависимость `pyserial` уже в `requirements.txt`.

Без Arduino оставь `INPUT_BACKEND = "auto"` — если плата не найдена, ввод пойдёт
через Windows (`pydirectinput`).

## Горячие клавиши (работают поверх игры)

- **F12** — аварийный стоп бота.
- **F10** — аварийно убрать оверлеи (рамки).
- Пауза/старт — кнопками в панели. После «Старт» даётся ~3 c переключиться в
  окно игры.

## Если что-то не так

- **«Python (pythonw) не найден»** — Python не установлен или не в PATH
  (шаг 1). Переустанови с галочкой «Add Python to PATH».
- **Ошибка про Tesseract / не читаются цифры и имена** — не установлен Tesseract
  или неверный путь в `config.TESSERACT_CMD` (шаг 2).
- **Бот «нажимает», но в игре ничего не происходит** — игра не принимает
  программный ввод. Запусти панель **от администратора** (лаунчер это делает),
  а если не помогает — используй Arduino-мост.
- **Бот читает мусор / не находит мобов / не видит HP** — не откалиброван под
  этот ПК. Пройди калибровку заново (раздел выше).
- **Рамки мобов обновляются редко** — слишком большая «Зона поиска». Сузь её
  по реальной игровой области.
